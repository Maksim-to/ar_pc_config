🌐 Сетевая топология
Устройства в системе:
Маршрутизатор (Router) - выполняет меж-VLAN маршрутизацию

Коммутатор (Switch) - L2 коммутатор с VLAN

ПК1 (VLAN 10) - компьютер в виртуальной сети 10

ПК2 (VLAN 20) - компьютер в виртуальной сети 20

Конфигурация VLAN:
VLAN 10: 192.168.10.0/24 (синий)

VLAN 20: 192.168.20.0/24 (красный)

🔄 Анимация передачи пакетов
Проект демонстрирует полный путь пакета при меж-VLAN коммуникации:

ПК → Коммутатор - передача в пределах access порта

Коммутатор → Роутер - передача по trunk каналу

Меж-VLAN маршрутизация - смена VLAN тега в роутере

Роутер → Коммутатор - возврат по trunk каналу

Коммутатор → ПК - доставка получателю

💡 Особенности реализации
Визуализация конвертов данных - анимированные пакеты в виде конвертов

Цветовая кодировка VLAN - синий для VLAN 10, красный для VLAN 20

Интерактивные устройства - кликните на любое устройство для просмотра конфигурации

Подробная информация - пошаговое описание процесса маршрутизации

🔧 Сетевые настройки
Конфигурация коммутатора:
text
interface Gi0/1
 switchport mode access
 switchport access vlan 10

interface Gi0/2  
 switchport mode access
 switchport access vlan 20

interface Gi0/3
 switchport mode trunk
 switchport trunk allowed vlan 10,20
Конфигурация роутера:
text
interface Gi0/0.10
 encapsulation dot1Q 10
 ip address 192.168.10.1 255.255.255.0

interface Gi0/0.20
 encapsulation dot1Q 20  
 ip address 192.168.20.1 255.255.255.0
