# AR Router-on-a-Stick Топология

Интерактивная система дополненной реальности для визуализации технологии межвланновой маршрутизации Router-on-a-Stick. Проект демонстрирует процесс передачи данных между виртуальными локальными сетями через 3D-визуализацию сетевой топологии в реальном времени.

## 🚀 Быстрый старт

Откройте проект по адресу: [https://maksim-to.github.io/ar_pc_config/](https://maksim-to.github.io/ar_pc_config/)

Разрешите доступ к камере вашего устройства, затем наведите камеру на маркер (pc-marker.png). Система автоматически распознает маркер и отобразит интерактивную 3D-визуализацию сетевой топологии.

## 📁 Структура проекта

- **index.html** — основной файл с AR-сценой и логикой приложения
- **pc-marker.patt** — шаблон для распознавания маркера
- **pc-marker.png** — изображение маркера для печати
- **router.obj** — 3D-модель маршрутизатора
- **switch.obj** — 3D-модель коммутатора  
- **computer.obj** — 3D-модель компьютера

## 🎯 Инструкция по использованию

Для работы с системой распечатайте файл pc-marker.png или откройте его на другом устройстве. Откройте index.html на смартфоне или планшете через HTTPS-соединение и наведите камеру на маркер.

Управление анимацией осуществляется через панель управления:

- **▶️ Старт** — запуск анимации передачи пакета между VLAN
- **⚙️ Конфигурация** — просмотр настроек сетевых устройств

## 🌐 Сетевая архитектура

Система визуализирует классическую топологию Router-on-a-Stick с следующими компонентами:

**Сетевые устройства:**
- Маршрутизатор (Router) — выполняет маршрутизацию между VLAN
- Коммутатор (Switch) — L2-коммутатор с поддержкой VLAN
- ПК1 (VLAN 10) — рабочая станция в виртуальной сети 10
- ПК2 (VLAN 20) — рабочая станция в виртуальной сети 20

**Конфигурация VLAN:**
- VLAN 10: подсеть 192.168.10.0/24 (синяя цветовая схема)
- VLAN 20: подсеть 192.168.20.0/24 (красная цветовая схема)

## 🔄 Процесс маршрутизации

Анимация демонстрирует полный цикл передачи пакета между VLAN:

1. Передача от ПК к коммутатору через порт доступа
2. Передача от коммутатора к маршрутизатору по магистральному каналу
3. Межвланновая маршрутизация на сабинтерфейсах роутера
4. Возврат пакета через магистральное соединение
5. Доставка пакета конечному получателю

## 💡 Функциональные возможности

Проект реализует интерактивную визуализацию с следующими особенностями:

- Анимированные пакеты данных в виде конвертов с цветовой кодировкой VLAN
- Интерактивные 3D-модели сетевых устройств с детальной информацией
- Пошаговое отображение процесса маршрутизации с пояснениями
- Визуализация trunk-соединений и access-портов

## 🛠 Технологический стек

- **AR.js** — фреймворк для реализации дополненной реальности
- **A-Frame** — фреймворк для создания 3D-сцен на WebGL
- **WebGL** — технология для отрисовки 3D-графики в браузере
- **WebRTC** — API для доступа к камере устройства

## 📱 Совместимость

## 🔧 Конфигурация сети

**Настройки коммутатора:**
interface Gi0/1
 switchport mode access
 switchport access vlan 10

interface Gi0/2  
 switchport mode access
 switchport access vlan 20

interface Gi0/3
 switchport mode trunk
 switchport trunk allowed vlan 10,20

**Настройки маршрутизатора:**
interface Gi0/0.10
 encapsulation dot1Q 10
 ip address 192.168.10.1 255.255.255.0

interface Gi0/0.20
 encapsulation dot1Q 20
 ip address 192.168.20.1 255.255.255.0
